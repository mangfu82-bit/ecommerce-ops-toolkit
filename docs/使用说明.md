# 电商运营工具包 - 使用说明

## 项目简介
12-Agent 电商智能运营中台，覆盖淘宝、美团、京东、抖音4大平台，支持数据采集、知识融合、决策分析、执行监控全流程。

## 快速开始

### 1. 安装依赖
```bash
pip install -r requirements.txt
```

### 2. 配置文件
复制 `config.example.yaml` 为 `config.yaml`，按需修改：
```bash
copy config.example.yaml config.yaml
```

### 3. 运行搜索
```bash
python src/main.py search
```
